# Natours – Full-Stack Tour Booking Application

Natours is a modern, full-stack web application for booking and managing tours. Built with a focus on security, performance, and maintainable code, this project demonstrates expertise in Node.js, Express, MongoDB, and dynamic frontend rendering with Pug.

---

## Key Features

- Browse and search tours with detailed information  
- Secure user authentication and authorization  
- Book tours and manage bookings  
- RESTful API endpoints for tours and users  
- Image handling and optimization for tours  
- Payment processing with Stripe  
- Dynamic frontend rendering using **Pug templates**  
- Data validation, sanitization, and security best practices  

---

## Technologies

**Backend:** Node.js, Express.js, MongoDB, Mongoose  
**Frontend:** Pug, HTML5, CSS3, JavaScript  
**Security & Utilities:** bcryptjs, jsonwebtoken, helmet, express-rate-limit, express-mongo-sanitize, xss-clean, slugify, validator  
**Other Tools:** Axios, Parcel, Nodemailer, Stripe, Sharp, Morgan, dotenv, Prettier, ESLint
